
# 🚀 Ultimate MERN E-Commerce (No Merge Needed)

## Features
- JWT Authentication
- Product CRUD
- Cart System
- Stripe Checkout Ready
- Admin Panel
- Modern UI

## Run Instructions

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm start

Add .env in server:
MONGO_URI=your_mongo_uri
JWT_SECRET=secret
STRIPE_SECRET_KEY=your_key
